## 3. 激活虚拟环境（Windows）

CMD：

```bat
D:
cd D:\credit-project\credit-decision-service
venv\Scripts\activate.bat
```

PowerShell：

```powershell
Set-Location D:\credit-project\credit-decision-service
.\venv\Scripts\Activate.ps1
```

激活成功的标志：命令行提示符前面出现 `(venv)`。

- 若 PowerShell 报「禁止运行脚本」，先执行一次：
  `Set-ExecutionPolicy -Scope CurrentUser -ExecutionPolicy RemoteSigned`
- 退出虚拟环境：`deactivate`
